# Дашборд из HTML

Нативный настольный интерфейс QML по приложенному `vexa_dashboard(2).html`.

## Что перенесено

- Дашборд: типографика, цвета, прямые разделители, группы активов, счета, ближайшее событие, график капитала, структура расходов, реестр операций.
- Неподвижный сайдбар с навигацией и состоянием активной страницы.
- Адаптация к ширине и высоте окна по правилам HTML: основной вид 1920×1080, более плотная компоновка на невысоких экранах, одна колонка и узкая навигация при ширине до 850 px. Минимальное настольное окно дашборда — 800×600.
- Встроенные оригинальные шрифты Arimo, Cousine, PT Serif, Gelasio. Базовые интервалы кратны 4 px; линии толщиной 1 px сохранены как в HTML.
- Счета прокручиваются внутри ограниченного блока с обрезкой содержимого. История не имеет собственного прокручиваемого контейнера: вместе с ней уходит вверх весь дашборд, включая заголовок. При 1920×1080 видны первые строки истории.
- Поиск, сортировка, выбор и повторное снятие выбора счёта, фильтр по категории расходов, период и валюта, действия с существующими окнами приложения. Правая кнопка мыши открывает прежние контекстные меню.
- Реестр создаёт только строки около видимой области, поэтому большая история не превращается в тысячи визуальных объектов.

Компоненты остальных страниц и `ui/mobile` не изменены. Общие редакторы счетов/операций, хранение данных, импорт и экспорт используют существующую реализацию проекта. Тестовые операции из HTML в пользовательскую базу не добавляются. График капитала продолжает использовать общую историю из `FinanceController`.

## Обновление по согласованной HTML-странице

Патч `vexa-dashboard-update.patch` применяется **поверх** `vexa-dashboard-desktop.patch`:

```sh
git apply --check /путь/к/vexa-dashboard-update.patch
git apply /путь/к/vexa-dashboard-update.patch
```

Убраны строка выпуска над заголовком, заголовки столбцов счетов, нижние элементы ближайшего события, кнопка CSV в реестре и подвал страницы. Заголовок и остальные блоки подняты на 32 px в обычном настольном виде и на 24 px в компактном. На каждой карточке показано количество счетов соответствующего вида, включая счета с нулевым остатком; криптокошельки и биржевые счета также учитываются, повторяющиеся идентификаторы считаются один раз.

В блоках графиков убраны крупные суммы и подписи к ним. График капитала увеличен до 168 px (152 px на невысоких экранах), содержит шесть горизонтальных делений и читаемые подписи шкалы. Диаметр кольца расходов также 168/152 px, надписи в центре убраны. Сохранены выбор категории через легенду, независимая прокрутка счетов, общая прокрутка дашборда и неподвижная навигация.

Проверено на Qt 6.10: тесты QML, снимки настольных размеров 1920×1080, 1600×960, 1440×900, 1280×800, 1024×768, 800×600, а также последовательное применение предыдущего и нового патчей. В этом обновлении C++ и настройки сборки не менялись; полная сборка приложения повторно не запускалась.

## Применение патча

Из корня исходного проекта:

```sh
git apply --check /путь/к/vexa-dashboard-desktop.patch
git apply --binary /путь/к/vexa-dashboard-desktop.patch
```

После применения заново запустите CMake и соберите приложение обычным для проекта способом. Требование Qt 6.10 остаётся прежним. Новые файлы QML и ресурсы шрифтов подключены в CMake.

## Проверка

```sh
cmake -S . -B build -DVEXA_BUILD_TESTS=ON
cmake --build build --target vexa UiNavigationTest WindowScrollInputTest
ctest --test-dir build -R 'UiNavigationTest|WindowScrollInputTest' --output-on-failure
```

Новые проверки находятся в `tests/qml/tst_editorial_dashboard.qml`: геометрия 1920×1080, размеры 1600×960, 1440×900, 1280×800, 1024×768 и 800×600, независимость прокрутки счетов и страницы, маршрутизация колесика мыши, виртуализация истории, переключение активов/счетов, поиск, сортировка, навигация и вызовы редакторов.

При необходимости снимки этих размеров можно получить, передав тесту существующий каталог через переменную окружения `VEXA_UI_CAPTURE_DIR`.
