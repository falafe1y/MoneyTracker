# Состояние страниц и прокрутка средним кликом

Патч 10 применяется поверх 09.

При переходах между разделами посещённая страница остаётся в памяти. Положение прокрутки, локальный ввод, выбранные варианты и раскрытые блоки сохраняются до закрытия приложения. Страница создаётся только при первом посещении; скрытые страницы не принимают ввод. Финансовые данные продолжают обновляться через прежние привязки. Выделение строк истории по-прежнему очищается при скрытии таблицы.

Раньше единственный загрузчик уничтожался вместе с прежним содержимым при каждом изменении раздела. Теперь настольная и мобильная оболочки используют общий компонент `CachedPages`.

Прокрутке средним кликом мешал прозрачный слой всплывающих элементов: после закрытия списка он мог остаться видимым. Поиск цели воспринимал сам слой как препятствие, возвращал пустую цель и не проверял страницу под ним. Теперь проверяются его видимые дочерние элементы, а пустой слой пропускается. Открытый список сохраняет приоритет над основной страницей. Скрытый список прекращает прокрутку.

Проверка вручную:

1. Прокрутите «Аналитику», измените способ группировки вложений и раскройте список выплат. Перейдите в другой раздел и вернитесь: настройки и положение должны сохраниться.
2. Откройте и закройте любой выпадающий список, затем нажмите колёсико над длинной страницей и отведите мышь от точки нажатия: страница должна прокручиваться. Повторите несколько раз.
3. Нажмите колёсико внутри открытого длинного списка: должен прокручиваться список. Закройте его и повторите на странице.

Автоматические проверки `UiNavigationTest` проверяют повторную навигацию, сохранение состояния и движение содержимого после закрытия списка. Проверки включаются в сборку при наличии модуля Qt Quick Test.
