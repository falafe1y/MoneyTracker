# Подключение Bybit

В «Добавить криптовалюту» укажите название счёта и выберите «Кошелёк» или «Биржа».
Для кошелька остаются USDT/TRC-20, Bitcoin и Ethereum и ввод публичного адреса.
Для биржи доступны Bybit, ключ API и секретный ключ.

## Что отображается

- Остатки по монетам и разделам биржи, а также их стоимость по готовой сводке Bybit.
- История единого торгового счёта и счёта финансирования: дата, направление изменения,
  описание, раздел счёта, сумма изменения и валюта.
- При первом подключении загружаются последние 30 дней. Затем история дополняется;
  повторные записи с тем же идентификатором не дублируются. Каждое обновление повторно
  проверяет последние два дня, чтобы учесть задержки биржи. После долгого перерыва
  запрашиваются максимум последние 30 дней.
- Обновление биржи раз в пять минут и по кнопке «Обновить». Данные сохраняются в базе
  и доступны после перезапуска. Ошибка загрузки оставляет предыдущую сводку и историю.

Поддерживается основной международный сайт Bybit (`api.bybit.com`). Региональные
сайты Bybit и старые торговые счета до перехода на единый счёт здесь не поддержаны.
Сводка остатков может показывать другие продукты, например накопления и торговых
ботов, если Bybit возвращает их в обзоре активов. Их отдельные истории не загружаются.
Сумма в истории — изменение остатка валюты, а не обязательно объём сделки. Например,
в журнале срочной торговли это может быть комиссия или расчёт по позиции.
Цена покупки, доходность и исторический курс доллара не рассчитываются.

## Ключи

Создайте в Bybit системный ключ API (пара «ключ / секрет», подпись HMAC) с доступом
**только на чтение**. Разрешите чтение данных торгового счёта и кошелька/финансирования.
Приложение проверяет признак доступа только на чтение до загрузки финансовых данных.
Если ключ ограничен адресами IP, адрес вашего компьютера должен входить в список Bybit.
При ошибке проверьте доступность основного сайта, права ключа и код ошибки в приложении.

Ключи не записываются в SQLite, резервные копии, журналы или аргументы командной строки.
На Windows они сохраняются отдельно и защищаются системным механизмом DPAPI текущего
пользователя; дополнительных DLL для этого устанавливать не требуется.
На Linux используется системное хранилище паролей через `secret-tool`.
Для Arch Linux понадобятся `libsecret` и работающая служба хранения паролей,
например `gnome-keyring` с настроенным запуском и разблокировкой в вашей сессии.

Если защищённое хранилище недоступно, подключение работает до закрытия приложения.
После перезапуска сохранятся остатки и история, но для обновления нужно снова ввести
ключи: правый клик по карточке → «Редактировать». На других устройствах или после
восстановления резервной копии ключи также вводятся заново. Удаление биржевого счёта
и очистка данных приложения удаляют его сохранённые ключи.

## Сборка и проверка

Патч применяется поверх последних изменений выделения и прокрутки:

```bash
git apply MoneyTracker-bybit.patch
```

Перезапустите настройку CMake и пересоберите приложение. Добавлен модуль Qt Concurrent
из того же комплекта Qt; сторонняя библиотека Bybit и OpenSSL для подписи не нужны.

Добавлен `BybitProviderTest`: подпись запросов, переход по страницам, недельные интервалы,
разделение счетов, отсутствие дубликатов, обработка ошибок, сохранение и очистка истории.
Тесты используют подставные ответы и не требуют настоящего ключа.
Проверена загрузка QML, переключение формы, отправка её значений и очистка полей ключей.
Полная сборка приложения и подключение к реальному аккаунту здесь не выполнялись.
Из существующих проверок базы 28 проходят; проверка очистки падает на пустом описании
перевода также в исходной версии, без этого патча.
